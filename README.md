# SatQuery AI

A conversational assistant for satellite and aerial imagery. Upload an
image, ask a question in plain language, and get an answer with visual
evidence (bounding boxes) where relevant.

Built for Smart India Hackathon.

## What it does

- **Describe** an image ("Describe this image")
- **Answer questions** about it ("What color is the water?")
- **Count and locate objects** ("How many ships are there?") with drawn
  bounding boxes
- **Compare two images of the same area from different dates** and report
  what changed

## Architecture

```
Frontend (React + Vite + Tailwind)
        |
FastAPI Backend
        |
Query Router
        |
    ------------------------------------------------
    |            |              |                  |
Captioning      VQA        Grounding/Detection   Change Detection
 (BLIP)       (BLIP-VQA)   (trained CNN / Faster    (image diffing)
                             R-CNN / OWL-ViT
                             fallback)
```

## Project layout

- `frontend/` — React app (upload, chat, bounding-box overlay, change-detection view)
- `backend/` — FastAPI app, ML services, training scripts
- `colab/` — GPU training notebook (all four models, checkpoints to Google Drive)
- `docs/` — dataset research and roadmap
- `datasets/`, `models/` — not committed (see `.gitignore`); regenerated by
  the training scripts / Colab notebook

## Running locally

```bash
# Backend
cd backend
python -m venv venv
venv/Scripts/pip install -r requirements.txt
venv/Scripts/python -m uvicorn app.main:app --port 8000

# Frontend
cd frontend
npm install
npm run dev
```
