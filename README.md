# SatQuery AI

A conversational assistant for satellite and aerial imagery. Upload an
image, ask a question in plain language, and get an answer with visual
evidence (bounding boxes) where relevant.

Built for Smart India Hackathon.

## What it does

- **Describe** an image ("Describe this image")
- **Answer questions** about it ("What color is the water?")
- **Count and locate objects** ("How many ships are there?") with drawn
  bounding boxes
- **Compare two images of the same area from different dates** and report
  what changed

## Architecture

```
Frontend (React + Vite + Tailwind)
        |
FastAPI Backend
        |
Query Router
        |
    ------------------------------------------------
    |            |              |                  |
Captioning      VQA        Grounding/Detection   Change Detection
 (BLIP)       (BLIP-VQA)   (trained CNN / Faster    (image diffing)
                             R-CNN / OWL-ViT
                             fallback)
        |
   PostgreSQL (image metadata, query history, comparison results)
```

## Project layout

- `frontend/` — React app (upload, chat, bounding-box overlay, change-detection view)
- `backend/` — FastAPI app, ML services, training scripts
- `colab/` — GPU training notebook (all four models, checkpoints to Google Drive)
- `docs/` — dataset research and roadmap
- `datasets/`, `models/` — not committed (see `.gitignore`); regenerated by
  the training scripts / Colab notebook

## Database

PostgreSQL — not a demo/optional layer, the API actually depends on it:

- `images` — every uploaded image (id, filename, content type, size, timestamp)
- `queries` — every question asked and its answer, linked to the image (real
  query history, exposed via `GET /images/{image_id}/history`)
- `comparisons` — every before/after change-detection result

Image *bytes* stay on disk under `uploads/`; Postgres holds metadata and
history. Tables are created automatically on backend startup from the
SQLAlchemy models in `backend/app/models_db.py` — no manual migration step
needed for local dev.

## Running locally

```bash
# 1. Create a local Postgres database named `satquery`
#    (createdb satquery, or via pgAdmin)

# 2. Backend
cd backend
python -m venv venv
venv/Scripts/pip install -r requirements.txt
cp .env.example .env        # then edit DATABASE_URL to match your local Postgres
venv/Scripts/python -m uvicorn app.main:app --port 8000

# 3. Frontend
cd frontend
npm install
npm run dev
```
